노션 데이터베이스로 개인 CRM 만드는 법

직장인이라면 누구나 소중한 인맥을 갖고 있습니다. 그런데 시간이 지나면서 명함은 쌓이고, 연락처는 흩어지고, 누가 어떤 일을 하는지 기억하기 어려워집니다. 이때 체계적인 인맥 관리 시스템이 필요한데, 비용 많이 드는 전문 CRM 솔루션 대신 무료로 사용할 수 있는 노션(Notion)으로 개인 CRM을 만드는 방법이 주목받고 있습니다.

이 글에서는 노션의 데이터베이스 기능을 활용해 실제로 업무에 도움이 되는 인맥 관리 시스템을 구축하는 방법을 단계별로 설명하겠습니다.

도입: 왜 개인 CRM이 필요한가?

개인 CRM의 역할

CRM은 'Customer Relationship Management'의 약자로, 본래 기업이 고객 관계를 관리하기 위한 도구입니다. 그런데 이 개념을 개인 차원으로 축소하면, 자신의 인맥을 체계적으로 관리하는 강력한 도구가 됩니다.

개인 CRM을 통해 할 수 있는 것들: - 연락처 이상의 정보 저장: 이름, 전화번호뿐 아니라 직무, 회사, 특기, 만난 경위 등 맥락 있는 정보 보관 - 커뮤니케이션 이력 추적: 마지막 연락 날짜, 주고받은 내용, 약속 사항 기록 - 관계 우선순위 관리: 중요도에 따라 연락 주기 설정 및 추적 - 기회 창출: 특정 프로젝트나 업무 필요 시 적합한 인맥을 빠르게 찾아 협력 요청

전통적으로 이런 기능들은 고가의 CRM 소프트웨어(Salesforce, HubSpot 등)가 제공했습니다. 하지만 개인이 이 정도 투자를 하기는 어렵고, 기능도 과합니다. 노션은 충분한 유연성과 기능을 무료로 제공하면서도 학습곡선이 완만해 개인용으로 이상적입니다.

핵심개념: 노션 데이터베이스의 이해

노션 데이터베이스란?

노션의 데이터베이스는 엑셀의 스프레드시트와 유사하지만, 훨씬 더 강력합니다. 각 행(row)은 독립적인 페이지로 작동하며, 다양한 속성(property)을 추가할 수 있고, 필터링, 정렬, 그룹핑 등의 고급 기능을 지원합니다.

개인 CRM 구축에 필요한 주요 데이터베이스 유형:

1. 연락처 데이터베이스

가장 기본이 되는 데이터베이스로, 모든 인맥 정보를 저장합니다.

필수 속성: - 이름 (Text): 연락처의 성명 - 직급/직책 (Text): 현재 직위 - 회사명 (Text): 근무 회사 또는 소속 - 직무 (Select): 마케팅, 개발, 영업, 인사 등으로 분류 - 연락처 (Phone): 전화번호 - 이메일 (Email): 이메일 주소 - 카테고리 (Select): VIP, 일반, 추천인 등 관계 유형 - 우선순위 (Select): 높음, 중간, 낮음 - 마지막 연락 날짜 (Date): 최근 소통 시점 기록 - 다음 연락 예정일 (Date): 계획된 다음 접촉 시점 - 메모 (Text): 특이사항이나 공통 관심사

2. 상호작용 로그 데이터베이스

각 사람과의 상호작용 기록을 남기는 데이터베이스입니다.

필수 속성: - 연락처 (Relation): 연락처 DB와 연결 - 상호작용 유형 (Select): 전화, 이메일, 카페 만남, 행사 참석 등 - 날짜 (Date): 상호작용이 발생한 시간 - 내용 (Text): 대화 내용이나 주요 논점 - 결과/후속조치 (Checkbox): 약속 사항이나 액션 아이템

이 데이터베이스는 "언제 누구와 무엇을 얘기했는가"를 명확히 보여줍니다.

3. 액션 아이템 데이터베이스

상호작용 중에 생긴 할 일들을 관리합니다.

필수 속성: - 제목 (Text): 액션 내용 - 담당자 (Relation): 연락처 DB와 연결 - 마감일 (Date): 할 일 기한 - 상태 (Select): 미시작, 진행 중, 완료, 보류 - 우선순위 (Select): 높음, 중간, 낮음 - 설명 (Text): 상세 사항

실전팁: 단계별 구축 방법

1단계: 노션 워크스페이스 설정

  1. 노션 회원가입 (www.notion.so): 이메일로 가입하거나 구글 계정으로 연동
  2. 새 페이지 생성: 좌측 사이드바에서 "+ Add a page" 클릭
  3. 이름 지정: "개인 CRM" 또는 "인맥 관리" 등 명확한 제목 지정
  4. 아이콘/커버 추가: 시각적 구분을 위해 이모지나 커버 이미지 설정 (선택사항)

2단계: 연락처 데이터베이스 생성

  1. 새 데이터베이스 추가: 메인 페이지에서 "+ Add a database" → "Table"이나 "Database" 선택

  2. 기본 구조 만들기: - 첫 번째 열은 자동으로 "Name" 속성이 됨 - 우측의 "+ Add a property" 클릭해 속성 추가

  3. 각 속성의 타입 설정: - 텍스트 입력: "Name", "회사명" - 선택형(Select): 직무, 카테고리, 우선순위 → 옵션 미리 입력 (예: 마케팅, 개발, 영업) - 날짜형(Date): "마지막 연락 날짜", "다음 연락 예정일" - 전화번호형(Phone): "연락처" (자동 포맷팅) - 이메일형(Email): "이메일" (클릭 시 메일 클라이언트 열림) - 멀티셀렉트(Multi-select): 관심사나 특기 여러 개 선택 가능

  4. 첫 번째 연락처 입력: 실제 데이터 몇 개를 입력해 구조 검증

3단계: 뷰(View) 설정으로 다양한 관점 확보

같은 데이터베이스를 여러 관점에서 볼 수 있게 뷰를 만듭니다.

뷰의 종류:

  • Table 뷰: 기본 테이블 형식 (모든 정보 한눈에)
  • Board 뷰: 칸반 보드 형식 (우선순위 또는 상태별로 그룹핑)
  • 카테고리별(VIP/일반/추천인)로 카드 정렬
  • 우선순위별(높음/중간/낮음)로 분류
  • Calendar 뷰: 캘린더 형식 (다음 연락 예정일 기준)
  • 언제 누구에게 연락할지 시각적으로 확인
  • Gallery 뷰: 사진 갤러리 형식 (프로필 사진 추가 시 유용)
  • Timeline 뷰: 관계 기간을 시간축으로 표현

각 뷰마다 필터를 적용하면 더욱 유용합니다.

뷰별 필터 예시: - "VIP 목록": 카테고리 = VIP - "이달 연락 필요": 다음 연락 예정일이 이번 달 내 - "완료되지 않은 액션": 상태 ≠ 완료

4단계: 관계(Relations) 설정으로 데이터베이스 연결

여러 데이터베이스를 연결하면 정보의 완성도가 높아집니다.

  1. 연락처 DB에 상호작용 로그 연결: - 연락처 DB에 새 속성 추가 → 타입 "Relation" 선택 - "상호작용 로그" 데이터베이스와 연결 - 이를 통해 각 연락처 페이지에서 해당 인물과의 모든 상호작용 기록을 볼 수 있음

  2. 양방향 연결 (Rollups): - 마지막 상호작용 날짜를 자동으로 계산하는 롤업 함수 사용 - 각 연락처마다 총 상호작용 횟수를 자동 집계

5단계: 템플릿 버튼으로 입력 자동화

반복적인 정보 입력을 줄이기 위해 템플릿을 활용합니다.

  1. 새 연락처 템플릿: - DB 우측의 "+ New" → "+ New template" 클릭 - 기본값으로 채울 정보 입력 (예: 카테고리 "일반", 우선순위 "중간") - 템플릿을 통해 새 항목 추가 시 이 값들이 자동 입력

  2. 상호작용 로그 템플릿: - 상호작용 유형별로 템플릿 생성 (예: "전화 통화", "이메일 송신") - 각 템플릿에 타입과 기본 형식 미리 입력

6단계: 필터링과 정렬로 실무 활용도 극대화

자주 쓰이는 필터:

  1. "이번 주 연락 필요": - 필터 조건: 다음 연락 예정일 ≥ 이번 주 시작일 AND ≤ 이번 주 마지막 날짜

  2. "1개월 이상 미연락": - 필터 조건: 마지막 연락 날짜 < 30일 전 - 이를 통해 관계를 소홀히 하는 인맥을 파악

  3. "직무별 전문가": - 필터 조건: 직무 = "개발" 또는 "마케팅" - 특정 프로젝트에 필요한 인재를 빠르게 찾음

정렬 옵션: - 마지막 연락 날짜 (오래된 순): 연락이 필요한 사람 우선 표시 - 우선순위 (높음 → 낮음): 중요도 순서 표시 - 회사명 (가나다순): 같은 회사 인맥끼리 묶기

주의점: 피해야 할 실수들

1. 과도한 속성 추가

문제점: 모든 가능한 정보를 속성으로 만들려다 보면 데이터베이스가 복잡해집니다. - 실제로는 자주 사용하지 않는 필드가 쌓임 - 새로운 연락처 입력 시간이 길어짐 - 유지보수의 부담 증가

해결책: - 최소 필수 속성부터 시작: 이름, 직급, 회사, 직무, 연락처, 메모 정도로 충분 - 사용 패턴 모니터링: 3개월 사용 후 실제로 활용되는 필드만 유지 - 메모 활용: 특이사항은 속성 없이 메모란에 작성

2. 데이터 입력의 일관성 부족

문제점: 같은 정보를 입력하는 방식이 다르면 나중에 검색과 필터링이 어렵습니다. - 회사명을 "(주)ABC", "ABC", "ABC주식회사" 등으로 다양하게 입력 - 직무를 "마케팅", "마케팅팀", "마케팅/광고" 등으로 다양하게 표기

해결책: - Select/Multi-select 타입 활용: 자유 텍스트 대신 미리 정의된 옵션에서 선택하도록 설정 - 입력 가이드라인 작성: 메모 필드에 어떻게 작성할지 예시 제공 - 정기적인 데이터 정제: 분기별로 중복이나 오류 수정

3. 자동 계산 함수 오남용

문제점: 롤업(Rollup)이나 포뮬라 함수를 과도하게 사용하면 데이터베이스가 무거워집니다.

해결책: - 필요한 계산만 사용: "마지막 연락 날짜 자동 업데이트", "며칠 지났는지" 정도만 - 복잡한 계산은 피하기: 고급 함수보다는 간단한 구조 유지

4. 개인정보 관리 소홀

문제점: 민감한 개인정보(휴대폰 번호, 이메일)를 노션에 저장할 때 보안 문제 발생 가능

해결책: - 노션 워크스페이스 공유 제한: 절대 공개 링크로 공유하지 않기 - 중요 정보는 암호화: 매우 민감한 정보는 별도 보안 도구에 보관 - 정기적인 권한 검토: 초대한 사람의 접근 권한 주기적으로 확인 - 계정 보안: 노션 계정에 2단계 인증 설정

5. 입력만 하고 활용하지 않기

문제점: 처음에는 열심히 입력하지만, 시간이 지나면서 관리 중단

해결책: - 주 1회 리뷰: 매주 월요일에 "이번 주 연락할 사람" 뷰 확인 - 모바일 알림 활용: 노션 모바일 앱에서 추가 설정 (유료 기능) - 간단한 로직부터: 처음부터 완벽함을 추구하지 말고 간단하게 시작해 발전시키기

FAQ

Q1. 노션 무료 버전으로도 충분할까요?

A: 네, 개인 CRM 구축에는 무료 버전으로 충분합니다. 무료 버전에서 사용 가능한 기능: - 무제한 블록 생성 - 모든 데이터베이스 유형 (Table, Board, Calendar, Gallery 등) - 필터링, 정렬, 그룹핑 - 기본 릴레이션 기능

유료 버전(Team, Business)은 팀 협업이나 고급 권한 관리가 필요할 때 고려하면 됩니다.

Q2. 기존 엑셀 데이터를 노션으로 옮길 수 있나요?

A: 네, 가능합니다. 방법: 1. 엑셀 파일을 CSV 형식으로 저장 2. 노션에서 새 데이터베이스 생성 3. 상단의 "Import" → "CSV" 선택 4. 파일 업로드 후 각 열을 적절한 속성으로 매핑

대량의 데이터 옮김 시 포맷 검증이 필요할 수 있습니다.

Q3. 스마트폰에서도 관리할 수 있을까요?

A: 네, 노션 모바일 앱(iOS, Android)을 설치하면 언제 어디서나 관리 가능합니다. 모바일 앱의 기능: - 데이터베이스 열기/검색 - 새 항목 추가 - 기존 항목 편집 - 오프라인 모드 (제한적)

다만 고급 기능(관계 설정, 필터 생성)은 데스크톱에서 하는 것이 낫습니다.

Q4. 얼마나 많은 연락처를 관리할 수 있나요?

A: 노션 데이터베이스는 이론상 수만 개의 레코드를 처리할 수 있습니다. 다만: - 개인 CRM의 실용적 규모: 200~500명 정도 - 1000명 이상으로 늘어나면 검색 속도가 느려질 수 있음 - 이 경우 연도별, 산업별로 데이터베이스를 분리하는 것이 좋음

Q5. 다른 사람과 공동 관리하려면 어떻게 해야 할까요?

A: 노션의 공유 기능을 활용합니다: 1. 페이지 우측 상단 "Share" 클릭 2. 이메일 주소로 초대 3. 권한 레벨 설정 (Can view, Can comment, Can edit)

팀 CRM으로 운영 시: - 각 팀원이 자신의 연락처 정보 관리 - 공유 데이터베이스에서 팀 차원의 중요 인맥 통합 관리 - 정기적인 리뷰 미팅으로 정보 동기화

Q6. 오래된 연락처는 어떻게 처리할까요?

A: 몇 가지 방법이 있습니다: 1. 아카이브 뷰: "상태" 속성에 "연락 중단" 옵션 추가하고, 조회는 하되 표시하지 않음 2. 별도 데이터베이스: "과거 연락처" 데이터베이스를 따로 만들어 보관 3. 삭제: 실제로 필요 없으면 영구 삭제

권장사항: 완전히 삭제하기보다 "비활성화" 상태로 표시해 나중에 필요할 때 참고할 수 있도록 합니다.

Q7. 노션 CRM이 실제로 비즈니스에 도움이 되나요?

A: 다음과 같은 경우에 큰 도움이 됩니다: - 영업직: 고객 현황 추적, 팔로우업 일정 관리 - 프리랜서/컨설턴트: 클라이언트 정보 관리, 프로젝트 히스토리 보관 - 네트워킹 활동: 콘퍼런스나 행사에서 만난 사람들 체계적 관리 - 채용/인사: 지원자, 협력 업체 담당자 정보 관리

실제 활용 예시: A씨는 노션 CRM으로 매월 30명씩 정기적 연락하며 새로운 프로젝트 기회를 평균 3개월마다 발굴한다고 보고했습니다.

결론

노션 데이터베이스로 만드는 개인 CRM은 직장인의 인맥 자산을 효율적으로 관리하는 강력한 도구입니다. 비싼 솔루션에 의존하지 않고도 자신의 비즈니스 필요에 맞게 커스터마이징할 수 있다는 것이 가장 큰 장점입니다.

성공의 핵심: 1. 간단하게 시작하기: 필수 정보 5~6개 속성으로 시작해 점차 확장 2. 일관성 유지하기: 정기적인 데이터 입력과 정제 습관이 중요 3. 적극적으로 활용하기: 만들기만 하고 방치하지 않기 4. 정기적 리뷰: 주 1회 이상 대시보드를 확인하고 액션 취하기

이번 가이드를 따라 개인 CRM을 구축하면, 앞으로 중요한 인맥을 절대 놓치지 않을 것입니다. 체계적인 인맥 관리는 단순한 정보 저장을 넘어 경력 발전과 비즈니스 성공의 초석이 될 것입니다.
